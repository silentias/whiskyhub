# WhiskyHub

**pre-alpha v0.0.3**

WhiskyHub — локальный голосовой ассистент с графическим интерфейсом для управления компьютером. Распознавание речи выполняется через Vosk, а синтез речи — через Piper. Голос и команды обрабатываются локально.

> На данный момент WhiskyHub поддерживает только Windows. Версии для Linux и macOS находятся в разработке.

## Установка и запуск

1. Скачайте `WhiskyHub-Setup.exe` из раздела **Releases**.
2. Запустите установщик и установите приложение.
3. Откройте WhiskyHub.
4. На главной странице нажмите кнопку включения WhiskyHub Engine.
5. При необходимости разрешите приложению доступ к микрофону.

При первом запуске Windows может показать предупреждение SmartScreen, поскольку pre-alpha-сборка пока не подписана коммерческим сертификатом.

## Использование

По умолчанию ассистента зовут **Виски**. Обращение и команду можно произнести отдельно:

```text
Виски
Открой браузер
```

Или одной фразой:

```text
Виски открой браузер
```

После завершения команды для нового запроса нужно снова обратиться к ассистенту по имени.

## Графический интерфейс

Десктопный интерфейс написан на React и работает внутри Tauri. На главной странице можно запускать и останавливать WhiskyHub Engine. В настройках доступно включение и выключение микрофона. Его фактическое состояние синхронизируется с Engine через локальный HTTP API.

## Локальные данные

При первом запуске создаётся папка:

```text
Документы\WhiskyHub\
├── assistant.db
├── commands.yaml
├── config.json
└── engine.log
```

- `assistant.db` — база SQLite с локальными данными ассистента;
- `commands.yaml` — пользовательская конфигурация команд;
- `config.json` — настройки приложения;
- `engine.log` — журнал ошибок голосового движка.

Существующие пользовательские файлы не перезаписываются при запуске новой версии. Новые встроенные команды дополняют пользовательский каталог в памяти.

## Архитектура

```text
React → Tauri/Rust → запуск WhiskyHub Engine
React → HTTP Adapter → CentralDispatcher → Core Actions
Микрофон → Voice Adapter → CentralDispatcher → Core Actions
```

Tauri управляет запуском и остановкой Python sidecar. Голосовой и HTTP-адаптеры преобразуют входящие действия в единый контракт команды, а `CentralDispatcher` выбирает необходимое действие ядра.

Локальный API доступен только на компьютере пользователя по адресу `http://127.0.0.1:8765`:

- `GET /api/health` — состояние Engine;
- `GET /api/microphone` — состояние микрофона;
- `PUT /api/microphone` — включение или выключение микрофона;
- `POST /api/commands` — выполнение команды по slug.

## Сборка из исходников

Потребуются Python, pnpm, Rust и Visual Studio Build Tools с компонентами C++.

Полная сборка выполняется из корня проекта:

```powershell
make release
```

Без установленного `make`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-release.ps1
```

Готовый NSIS-установщик появится здесь:

```text
release\WhiskyHub-Setup.exe
```
