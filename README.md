# WhiskyHub

WhiskyHub — локальный голосовой ассистент для управления компьютером. Распознавание речи и озвучка выполняются локально: для распознавания используется Vosk, для синтеза речи — Piper.

> Сейчас WhiskyHub доступен только для Windows. Поддержка Linux и macOS находится в разработке.

## Запуск

1. Скачайте архив Windows-версии из раздела **Releases** на GitHub.
2. Полностью распакуйте архив в отдельную папку.
3. Подключите микрофон.
4. Запустите файл `WhiskyHub.exe`.

Не перемещайте `.exe` отдельно от остальных файлов сборки: рядом с ним находятся модели распознавания и синтеза речи, необходимые для работы программы.

При первом запуске Windows может показать предупреждение SmartScreen. Также приложению может потребоваться разрешение на использование микрофона.

## Как пользоваться

По умолчанию имя помощника — **Виски**. Сначала произнесите имя, а затем команду:

```text
Виски
Открой браузер
```

Можно произнести обращение и команду одной фразой:

```text
Виски открой браузер
```

## Доступные команды

| Действие | Голосовые команды |
|---|---|
| Открыть браузер | `Открой браузер` |
| Открыть калькулятор | `Открой калькулятор` |
| Открыть блокнот | `Открой блокнот` |
| Открыть проводник | `Открой проводник` |
| Открыть терминал | `Открой терминал` |
| Открыть календарь | `Открой календарь` |
| Сообщить дату и время | `Сообщи время и дату`, `Скажи время и дату`, `Который час`, `Какое сегодня число` |
| Открыть диспетчер задач | `Открой диспетчер задач` |
| Открыть настройки Windows | `Открой настройки` |
| Изменить имя помощника | `Смени имя на <имя>`, `Называйся <имя>`, `Теперь тебя зовут <имя>` |
| Очистить корзину | `Очисти корзину` |
| Выключить компьютер | `Выключи компьютер`, `Заверши работу компьютера` |
| Перезагрузить компьютер | `Перезагрузи компьютер`, `Перезагрузи ПК` |

## Подтверждение опасных команд

Очистка корзины, выключение и перезагрузка компьютера выполняются только после дополнительного подтверждения.

Для подтверждения скажите:

```text
Подтверждаю
```

Также поддерживаются фразы `Подтвердить` и `Да`.

Для отмены скажите:

```text
Отмена
```

Также поддерживаются фразы `Отмени` и `Нет`.

## Локальные данные

Приложение хранит настройки и имя помощника локально на компьютере пользователя. Для основной работы WhiskyHub не требуется отправлять распознанную речь в облачные сервисы.
